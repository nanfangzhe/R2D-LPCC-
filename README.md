# R2D-LPCC-
This repo contains the code for our paper: R2D-LPCC: Relevance-Ranking Guided Region-Adaptive Dynamic LiDAR Point Cloud Compression.
Our method introduces a multi-source fusion-based relevance ranking mechanism that integrates semantic, motion, and structural cues to assess the importance of different regions and guide compression accordingly. We design a Multi-scale Region-Adaptive Transform (MRAT) module to enhance semantic feature modeling and preserve fine details in key regions, embedded within both the encoder and decoder. Additionally, we develop an adaptive multimodal motion estimation module to improve motion compensation in complex 3D scenes. Extensive experiments on the SemanticKITTI benchmark demonstrate that R²D-LPCC significantly outperforms ten recent state-of-the-art methods, achieving a 98.58\% BD-rate reduction compared to the GPCC standard, while maintaining superior reconstruction quality in semantically important regions.
